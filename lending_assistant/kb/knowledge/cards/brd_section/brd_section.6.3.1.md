**In short:** Section 6.3.1 lists nine validation outcomes with the message the partner sees and whether the problem can be put right.

## What this section says

BRD 6.3.1 (PDF page 33) has a table of nine outcomes, each with the message shown to the partner and whether it is recoverable. Account not found: recoverable by inline edit. Account dormant: recoverable after the customer reactivates it at a branch. Account closed: not recoverable. Account frozen: not recoverable, referred to the Bank. Name mismatch: recoverable by inline edit. KYC expired: recoverable after the customer updates it at a branch. Ineligible account type: not recoverable. Duplicate active application: not recoverable. Validation unavailable: automatic, with the message “Validation is temporarily unavailable. Retrying automatically.”

## Why the bank wants it

The BRD doesn't say why; the usual reason is that a partner clerk can fix a file only if each message tells them what is wrong and whether it is theirs to fix (PDF page 33).

## How it meets Frappe Lending

This section holds no requirement row, so there is nothing in it to compare with Frappe Lending, and the team has made no statement about it. It describes the origination system (LOS), which the team has not analysed.
