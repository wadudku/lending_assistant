**In short:** Bank staff can search across all applications by NID, mobile number, account number, applicant name, partner, batch reference and loan account number.

## What the rule says

BR-LOS-211 (Must, BRD 6.10.1, PDF page 44) says Bank staff "shall be able to search across all applications by NID, mobile number, account number, applicant name, partner, batch reference and loan account number". That is seven search keys, and the search covers all applications, not only one partner's.

## Why the bank wants it

The BRD doesn't say why; the usual reason is that a person asking about an applicant can quote any one of these identifiers, and Bank staff need to find the application from whichever they have.

## Example

A partner calls the Bank about one applicant and gives only the mobile number. Bank staff search all applications by that number and find the application.

## Terms to know

- **NID:** National Identity Document, as the BRD's glossary spells it.
- **Batch reference:** the reference of the batch an application belongs to, as the BRD uses the term.
