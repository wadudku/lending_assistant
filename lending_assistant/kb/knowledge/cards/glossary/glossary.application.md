**In short:** One prospective loan. In a partner's file, one row is one application.

## Plain meaning

The BRD defines an application as one prospective loan, and as one row of a partner-submitted file (BRD 1.5).

## Example

A partner sends a file of 300 rows. That is 300 applications. Each one gets its own status from DRAFT onwards (BRD 5.2).

## Why it matters here

Almost every origination rule is about one application: it is scored, sampled, sanctioned and handed to servicing. The team has analysed only the LMS requirements (Section 7). The LOS requirements have not been analysed.
