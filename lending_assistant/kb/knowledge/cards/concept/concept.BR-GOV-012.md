**In short:** The same word means the same thing on every screen, report and extract, and where the bank has its own word for a state, the bank's word is used.

## What the rule says

BR-GOV-012 (Must, BRD 3.4, PDF page 20) says terminology is identical across every user interface, every report and every extract. Where the Bank's existing systems use different terminology for an equivalent state, the Bank's terminology is adopted, so that one vocabulary describes one loan.

## Why the bank wants it

The BRD gives the reason in the row itself: so that one vocabulary describes one loan (BR-GOV-012, PDF page 20).

## Example

The bank calls a loan that is behind on payments “overdue”, while a generic system calls it “delinquent”. The bank's word “overdue” appears on every screen, report and file.

## Terms to know

- **Vocabulary:** the set of words used for statuses, fields and reports.
- **Extract:** a data file taken out of the platform.
- **Equivalent state:** a state that means the same thing under two different names.
